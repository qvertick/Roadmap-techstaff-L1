# Testaff L1 — Roadmap

Интерактивная дорожная карта знаний и навыков для специалиста техподдержки первой линии (L1).
Прогресс отмечается чекбоксами, сохраняется автоматически и подгружается при следующем открытии страницы.

## Структура проекта

```
l1-support-roadmap/
├── index.html   разметка страницы (шапка, вступление, схема сети, сайдбар, модалка)
├── style.css    все стили (тема, анимации, адаптив, печать)
└── script.js    вся логика (данные роадмапа, прогресс, темы, поиск и т.д.)
```

## Как запустить

Просто открой `index.html` в браузере — сборка не нужна.

Для локальной разработки удобнее поднять любой статический сервер (чтобы `fetch`/относительные пути точно работали одинаково в разных браузерах), например:

```bash
cd l1-support-roadmap
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Хранение данных

Прогресс, выбранная тема и «профиль» (лёгкая идентификация по имени, без настоящего OAuth) сохраняются через:

- `window.storage` — если страница открыта внутри Claude (Artifacts storage);
- `localStorage` — как фолбэк в обычном браузере.

Ключи хранилища:

| Ключ | Что хранит |
|---|---|
| `l1_support_progress_v1::<profile>` | отмеченные пункты чек-листа |
| `l1_profile_v1` | текущий «профиль» (имя) |
| `l1_theme_v1` | выбранная цветовая тема |
| `l1_tip_dismissed_v1` | дата, когда закрыли «совет дня» |

У каждого профиля свой прогресс (гостевой прогресс хранится отдельно от именных).

## Как редактировать содержимое роадмапа

Все пункты, категории и кластеры лежат в одном месте — массив `DATA` в начале `script.js`:

```js
const DATA = [
  { code:'TECH', title:'Технические знания', categories:[
    { code:'OS-01', title:'ОС: Windows и macOS', items:[
      { id:'os1', text:'Установка, настройка и базовое восстановление ОС' },
      ...
    ]},
    ...
  ]},
  ...
];
```

- `code` кластера/категории — короткий технический идентификатор, используется в DOM-id и в кнопках быстрой навигации (`data-target`).
- `id` пункта — должен быть уникальным по всему файлу (используется как ключ прогресса).
- Порядок кластеров/категорий/пунктов = порядок отображения на странице.

Чтобы добавить новый раздел — достаточно дописать объект в `DATA`, весь UI (счётчики, прогресс-бары, поиск) перестроится сам.

## Фичи интерфейса

- **Вступление + схема сети** — статичный блок вверху страницы, чисто для контекста и антуража.
- **Поиск** (`/` — фокус на поле) — фильтрует пункты по тексту, не трогает сохранённый прогресс.
- **Быстрая навигация** — чипы-кнопки скроллят к нужному кластеру.
- **Совет дня** — показывается раз в сутки, закрывается крестиком и не всплывает повторно в этот день.
- **Темы** — 4 готовые цветовые схемы (Неон / Матрица / Закат / Лёд), переключаются в сайдбаре.
- **Копировать сводку** — кладёт в буфер обмена текстовый отчёт по прогрессу.
- **Печать / PDF** — отдельные print-стили: убирают сайдбар/тулбар, оставляют чистый список для печати.
- **Адаптив** — сайдбар прячется в бургер-меню на экранах уже 900px.

## Технологии

Чистый HTML/CSS/JS, без сборки и зависимостей. Шрифты — IBM Plex Sans/Mono с Google Fonts (CDN).
