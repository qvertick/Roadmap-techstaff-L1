# Testaff L1 — Roadmap

Интерактивная дорожная карта знаний и навыков для специалиста техподдержки первой линии (L1).
Прогресс отмечается чекбоксами, сохраняется автоматически и подгружается при следующем открытии страницы.

## Структура проекта

```
l1-support-roadmap/
├── index.html   разметка страницы (шапка, вступление, схема сети, сайдбар, модалка)
├── style.css    все стили (тема, анимации, адаптив, печать)
└── script.js    вся логика (данные роадмапа, прогресс, темы, поиск и т.д.)
```

## Как запустить

Просто открой `index.html` в браузере — сборка не нужна.
